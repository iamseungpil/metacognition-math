## 0. 의도 (고정)

> 특정 언어 패턴인 메타인지를 · 내부 신호를 활용해 · 강화하려는 셀프 디스틸레이션 시도.

- 언어 패턴 = 모델이 한 풀이 안에서 스스로 여는 되짚기 구간(첫 `\boxed` → 마지막 `\boxed`). 검산·방향 전환 모두 포함, 주입 없음.
- 내부 신호 = 형제 롤아웃의 LOO 다수결 답(정답지 대신), 보조로 PMI 믿음 이동.
- 셀프 디스틸레이션 = 외부 교사 없이 정책 자신의 롤아웃 합의가 교사.
- 정확도는 목표, 메타인지 버릇은 수단. 세 층으로 나눠 검정한다:
  **A 측정**(그 행동이 정확도에 도움 되나) → **B 자**(내부 신호로 좋고 나쁨을 잴 수 있나) → **C 학습**(그 신호로 RL 하면 행동·정확도가 오르나).

## 2. 계열별 회고

### 2.1 자리 반사실 라벨 (층 B, 0914) — 실패, 견고
- **가설**: 풀이 중간 자리에 verify/redirect 메타를 심어 보면 어느 판단이 옳은지 라벨이 생긴다.
- **방법**: 무작위·결판 미정·자발 메타 자리 200~400곳, K=8~32, 관문 SAVE ≥ 5% ∧ tie ≤ 80%.
- **결과**: tie 88~93.5%, SAVE 0~2.8%, own ≈ donor(+.025 대 +.024), 자발 메타 위치 .80 = 답이 정해진 뒤의 사후 진술(R:30-120).
- **해석**: 메타 문장을 끼워 넣어도 답이 거의 안 바뀐다. **자리에 무엇을 넣든 라벨 밀도가 안 나온다** — 여섯 번 반복된 결론. 수정 2(K=32 이른 자리)는 끝내 돌지 않았다.

### 2.2 은닉·불확실성 자 (층 B, 0914~15) — 실패, 표본은 작음
- **가설**: 모델은 이 시도가 틀렸음을 내부적으로 안다(은닉 상태·형제 기하·확신도·로그확률).
- **방법**: 끝 은닉 프로브, 형제 중심 거리(G1, 관문 문제 안 AUC ≥ .65), 12지표 결합(G10), 반면교사 자(S1), 기억상실 교사(B1).
- **결과**: 문제 안 AUC 천장 ≈ .57(.511~.577), 재채점 후 ±.02, S1 ≈ .50, B1 은 길이 인공물(R:147-162, 280-290, 492-553, 742-747).
- **해석**: **한 롤아웃의 내부 상태로는 문제 안에서 정오를 못 가른다.** 풀링 AUC(.78~.86)는 문제 난이도를 잰 것이다. 단 결판 미정 문제가 38~161개뿐이라 «없다»보다 «못 봤다»에 가깝다(H:193-201).

### 2.3 문맥 안 재시도 · redirect (층 A/C, 0914~17) — 실패, 가장 견고
- **가설**: 틀린 답을 쓴 뒤 같은 문맥에서 «다시 보라»고 하면 구제된다.
- **방법**: 정박 진단(모드당 1,248행), M_RETRY RL, g12(8k), O1 브리지, g17 강제 장고.
- **결과**: 두 번째 답 정답 0/1,248, 심은 redirect 의 95.6% 가 스스로 verify 로 뒤집힘, 문맥 안 .252 대 독립 재풀이 .600(−.348), 브리지 .163 대 리셋 .577, 강제 장고 .320 대 blind .626(R:328-354, 474-490, 777-803).
- **해석**: **자기 오답이 문맥에 있으면 모델은 그 답에 끌려간다(끌개).** 주입형 재시도는 닫는다. 자발적 수정이 가치 있는 이유가 여기 있다 — 모델이 스스로 열 때만 작동한다.

### 2.4 비판 · 계획 · 진단 · 지시 내용 (층 A, 0914~16) — 실패
- **가설**: 메타 문장의 «내용»(자기 비판, 풀기 전 계획, 불일치 진단, 검산 지시)이 정답률을 바꾼다.
- **방법**: G4/g12 비판 재풀이, G5 정보이득 자, G6 계획(donor 대조로 max-of-3 편향 제거), g11b 진단, g15 지시형, V1 검산 수행(filler·pad·reread 대조).
- **결과**: 8k 재실행에서 자기 .566 = 남 .567 < 눈감음 .600, G5 자기−donor −.0256, G6 +.012 CI∋0, g11b 진단 .698 < 다수결 .725, g15 filler 만으로 +.041, V1 confirm +.020 CI∋0(R:356-532, 657-674, D:166-187).
- **해석**: **내용 효과는 0이고, 이득은 «더 쓰게/더 읽게»로 전부 설명된다.** 모든 개입에 길이·filler·donor 대조를 붙여야 한다는 규칙이 여기서 나왔다.

### 2.5 리셋 재풀이 (층 A → C, 0915~21) — 측정은 소폭 양성, 학습은 실패
- **가설**: 풀이 본문을 버리고 «이전 답은 X였다» 한 줄만 주고 다시 풀게 하면 오른다(G8·F1). 그것을 RL 로 옮기면 습관이 된다(S3).
- **방법**: G8(오답 150 + 정답 150, K=8, 8k), F1 리셋 자리 내용(notx·pad·donor), T0 규칙 프로토콜(등토큰), S3 2시도 리셋 RL, H1 요인설계 7셀.
- **결과**: G8 +3.42pp [+.0017,+.0650](재채점 기록 없음), F1 notx vs fact +.062, pad 대비 +.038 CI∋0, T0 gated_fact = maj16 정확도에 더 적은 토큰, S3 30스텝 무신호·수정 습관 2.91 → 1.70%, H1 오라클 최대 .871 < 관문 .9095(R:615-632, 727-729, 791-793, 1091-1101, D:235, 281).
- **해석**: **리셋은 «추론 시 계산을 더 쓰는 프로토콜»이지 메타인지 습관이 아니다.** 이기는 셀은 추론 때 형제·gold 정보가 필요해 의도와 맞지 않는다. 2턴은 1턴 예산을 잘라 출발선부터 −7pp.

### 2.6 결정 발화 · 수정 습관 SFT (층 C, 0917~18) — 실패
- **가설**: 좋은 결정 문장이나 수정 궤적을 SFT 로 가르치면 습관이 된다.
- **결과**: 결정 SFT 발화 .834 대 pass@1 .046(풀이 붕괴), 수정 습관 SFT 수정률 2.59%(데이터에 평가셋 L5 800 누출)(R:884, 913-917, D:260).
- **해석**: 고정 문형 모방은 풀이를 망가뜨리고, 증류만으로는 습관이 안 큰다.

### 2.7 자발적 답 수정의 발견 (층 A/B, 0917) — 성공, 축의 근거
- **가설**: 모델이 스스로 첫 답을 바꾸는 행동은 자기 오답 탐지다.
- **방법**: base L5 800 × 8 전수, 문제 안 짝비교(109그룹).
- **결과**: 수정률 2.9%(8k)/4.19%(12k), 문제 안에서 수정한 풀이의 첫 답 오답률 .826 대 안 한 풀이 .303, AIME 망침 0(R:830-864, V).
- **해석**: **진술형 메타 신호는 짝비교에서 전부 사라지고, 자발적 수정 «행위»만 살아남았다.** 이것이 현행 축이다. 다만 base 에서 수정이 벌어 주는 순이득은 1.52pp 뿐이라 정확도 기대치의 상한이 낮다.

### 2.8 PMI 믿음 이동 자 (층 B, 0917~21) — 통과로 기록, 근거는 약함
- **가설**: 되짚기 구간의 앵커 답 로그확률 이동(PMI shift)이 좋은 수정과 나쁜 수정을 가른다.
- **방법**: 첫 박스 직후 → 마지막 `\boxed` 직전, 디코이·위약 대조, gold/다수결 앵커.
- **결과**: 수정 행 +27.7~+37.6 대 위약 +4.5~+6.5(6/6 PASS), shift_check 문제 안 AUC .906(위약 .487)(R:919-929, V).
- **해석과 한계**: .906 은 H1 **2턴 텍스트**에서 쟀고, 닫는 자리가 곧 쓸 최종 답 직전이라 «곧 쓸 답의 확률로 그 답의 정오 맞히기»에 가깝다(동어반복 의심, R:890). 0918 관문 (c)는 7·4문제였다(D:249). **단일 패스에서, 구간 안쪽 자리로 다시 재기 전에는 보상에 쓰지 않는다.**

### 2.9 자발 수정 + 크레딧 RL (층 C, 0918~23) — 전부 실패, 원인은 칭찬 구조

## 3. 다음 실험에 쓰는 규칙 (이 회고에서 나온 것)

1. **발사 전 스텝 1 덤프(또는 저장된 덤프 재적용)로 행 종류별 칭찬 부호를 확인한다.** 구간 앞과 구간 안을 따로 본다(v5 는 구간 안만 봐서 구멍을 놓쳤다).
2. **칭찬은 조각별로**: 첫 답을 만든 부분은 첫 답 점수, 되짚은 부분은 나아진 만큼. 앵커(β·KL)로 사행을 누르지 말고 구조로 없앤다.
3. **습관은 고정 자리 측정기로 잰다**: 같은 «첫 답까지» 풀이 400개를 모든 체크포인트에 이어 쓰게 해 «틀릴 때 다시 보기·고치기 / 맞을 때 괜히 보기·망치기»를 잰다. 12k 평가는 25스텝 최종에만.
4. **모든 개입에 길이·filler·donor·순수 GRPO 대조**를 붙인다(2.4, Spurious Rewards).
5. **예산은 12k 로 고정**하고 절단률을 조건별로 보고한다(2.5, 1-2).
6. **사행 감시는 gold 첫 답 정확도로**, 학습 신호는 다수결로(누수 없음).
7. **정확도 관문은 현실적으로**: 수정 순이득 상한 1.52pp, 탐지 한계 ±1.14pp. 25스텝 관문은 수정률 ≥ 6% ∧ 정밀도 유지 ∧ 정확도 비열등, 이득 주장은 50스텝 연장 뒤.
8. **닫힌 축은 다시 사지 않는다**: 자리 반사실 라벨, 은닉 자, 주입형 재시도·2턴, 메타 내용, 고정 문형 SFT, 필요 행만 크레딧, 보상 항 앵커.

## 4. 현행 계획 (0923, 사전등록 수정 17)
