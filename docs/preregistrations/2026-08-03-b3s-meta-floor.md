# 사전등록 — B3 + `dcpo_meta_floor` (arm `rq3v2f_b3s`)

**⚠ 정직성 표기**: 이 문서는 **발사 후에 작성되었다**(잡 `musical-wombat`, 2026-08-03 ~10:00 UTC 발사,
작성 시점 gs≈6). 나는 "동결 후 발사"라고 말해놓고 순서를 어겼다. 아래 판정 규칙은 **gs6 시점의
지표만 본 상태**에서 썼고 판정 지점(gs50·gs150·gs300)의 어떤 수치도 보지 않았다. 그럼에도
사후 작성이라는 사실이 이 문서의 지위를 낮춘다는 점을 명시한다.

## 1. 무엇을 재는가

`b3p`는 사전등록된 B3 triobj 패키지를 `dcpo_meta_floor=0.0`으로 돌렸고 `dcpo/meta_emit_rate`가
gs150까지 1.00 → 0.018로 무너졌다. gs150~300은 **처치가 부재한 모델**을 측정했으므로 **Outcome C**다.

통제군 `b2p`(같은 init·같은 데이터·메타 보상 없음)는 `val-aux/*/meta_structure`가 **300스텝 내내
0.1000으로 평평**했다. 붕괴는 기질이나 길이 압력이 아니라 **b3p가 추가하는 것**에 있다.

**이 arm은 그중 한 노브만 되돌린다: `dcpo_meta_floor 0.0 → 0.05`.**
`CODE_TAR_REVISION`(490407111)과 `--config-name`(`triobj_dcpo_v4_stage3b_h100_4x4k`)이 b3p와
동일하므로 차이는 그 한 줄이다.

## 2. 팔과 대조

| 팔 | init | 보상 | floor |
|---|---|---|---|
| `rq3v2f_b3s` (처치) | `b2p2_rvfull_sft` | B3 triobj 패키지 | **0.05** |
| `rq3v2f_b2p` (통제군, 기존) | 동일 | vanilla GRPO | 해당 없음 |
| `rq3v2f_b3p` (참조, 완료) | 동일 | B3 triobj 패키지 | 0.0 |

주 대조 **`b3s − b2p`**. 부수 대조 `b3s − b3p`(floor 단독 효과).

## 3. 판정 규칙 (고정)

### 게이트 — 하나라도 실패하면 무효
| 시점 | 조건 |
|---|---|
| gs25 | `meta_emit_rate` ≥ 0.80 · `pmishift_attempted_rate` ≥ 0.30 · `n_save` > 0 · `actor/entropy` > 0.1 |
| **gs50 (킬 게이트)** | **`meta_emit_rate` ≥ 0.80. 미달이면 즉시 중단** — floor가 붕괴를 못 막는다는 뜻이고 원인은 `w_meta` 또는 `anchor_norm`으로 좁혀진다 |
| gs150 | `meta_emit_rate` ≥ 0.80 **유지** |

### 주 지표
**MATH500 level 4–5 (n=262)** 의 `Δacc(L4–5) − Δacc(L1–2)`, 문항 페어드 부트스트랩 10,000회.
바닥 0.00 · 천장 +29.97 · **잡음바닥 ±3.08pp**(같은 모델 8샘플 4/4 A-vs-A 실측).
판정 지점 **gs150·gs300**, 둘 다 보존(`--keep 3`).

### 결과 정의
| | 조건 |
|---|---|
| **양성** | 게이트 전부 통과 **그리고** `b3s − b2p` 95% CI 하한 > **+3.0pp** |
| **판정 불가** | CI가 +1.0~+3.0pp 밴드에 걸침 — n=262로는 양성도 음성도 아니다. **미리 선언한다** |
| **음성** | 게이트 통과했는데 CI 상한 < +1.0pp ⇒ 발화를 살려도 이득이 없다 |
| **무효(C)** | gs50 또는 gs150 게이트 실패 |

⛔ **in-training val594는 판정에 쓰지 않는다** — 셀당 21~38문항, 한 문제가 2.6~4.8pp.

## 4. 알려진 한계 (사후 설명으로 쓰지 않기 위해 미리 적는다)

1. **단일 학습 시드.** 전 팔 공통.
2. **floor 0.05는 instruct에서 검증된 값이 아니다.** git 이력상 성공한 `shiftonly`(런처 2026-07-06 생성)는
   floor **0.0**으로 돌았다(0.05 → 0.0 전환은 2026-06-22 `f1f6cec`). 0.05는 `CONSTITUTION.md` Part V의
   **처방**이지 재현이 아니다.
3. **floor는 무조건 견인력이라 쓸모없는 발화도 붙잡는다.** 발화가 유지되면서 이득이 없는 결과는
   "always-on 메타"라는 반대편 실패일 수 있고, 그 구분에는 placebo 팔이 필요하다(미실시).
4. **`len_cost 0.08`은 그대로 켜져 있다.** 붕괴의 또 다른 유력 후보이며 이 팔은 그것을 검정하지 않는다.
   후속 팔 `b3p + len_cost=0.0`이 그 자리다.
5. **관측용 3종**(`val_before_train=True` · `log_val_generations=8` · `--keep 3`)은 학습 궤적에
   영향을 주지 않지만 b0p·b2p에는 없으므로 **로그 산출물의 종류가 팔마다 다르다**.
