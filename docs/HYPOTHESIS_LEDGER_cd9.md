추정이라 «혼합» 판정 자체가 흔들린다. ③ 선형 프로브·코사인이라는 자의 표현력. ④ 비-thinking
모드(정책이 내부 상태를 «다시 읽을» 계산 여유 자체가 없다). ⑤ 8k 예산 잘림 7%.
**단, math500 소표본 .724 가 L5 에서 .511 로 무너진 것은 «작은 n 이 위로 튄다»는 방향을 이미
한 번 실증했다** — 같은 함정이 이번 .577 에도 걸린다.

### H1c 행동 신호 — **지지, 그러나 자기지식이 아니다**
재계산 결과(C1). 형제 답 점유율은 문제 안 .754, 발화행 .814로 **모든 내부·언어 신호를 압도**한다.

### H3 통제(행동) — **기각**
C4 재계산 + M_RETRY/SL 로그. 문맥 안 재시도의 구제 0~1.7%, 재기입 85~86%, 심은 지시의

**배제 못 한 대안**: ① 정박은 «문맥 안» 특유의 현상이므로 **문맥을 끊은 설계는 G4 하나뿐**이고

않았다.** ④ 비-thinking 모드. ⑤ 2~5 스텝은 행동 학습에 짧다.

### H4 형제 라벨 품질 — **혼입(사실상 미검정)**
자리 라벨: tie 88~99%, SAVE 0~2.8%(게이트 5%). 재시도 라벨: 진리표는 정의되나 결정 분포가

M_AGREE 계열(형제 다수파 표적)은 라벨 품질이 가장 좋았으나(불일치 예측 .778) **한 스텝도 안 돌았다**.
**배제 못 한 대안**: 라벨이 나빠서가 아니라 **행동 채널(H3)이 막혀 라벨이 쓰일 자리가 없었을**
가능성. H3 와 H4 는 이 설계에서 분리되지 않는다.

### H5 GRPO 메타 스팬 증폭 — **미검정 · 구조적으로 치명**
직접 게이트가 없다. 그러나 (a) 분산 분해상 은닉 신호의 **77%가 문제 간**이고 그룹 중심화가

분산이 0 → 어드밴티지 0, (c) M_PROBE 는 스코어러 미배선으로 M_G1 과 동치, (d) M_JUDGE/M_RAND 는

## 2. 실패 설명력 순위

1. **H3(통제 채널) + H5(증폭 채널)** — 이 둘이 0 이면 H1/H2/H4 가 무엇이든 곱은 0 이다.

   스코어러 미배선). **가장 큰 설명력.**
2. **H1b(시도 단위 신호)** — 신호가 문제 간에만 있고 GRPO 는 문제 간을 지운다. H5 를 구조적으로
   불가능하게 만든 원인. 단 검정력 부족(38문제)으로 «없다»가 아니라 «못 봤다»에 가깝다.
3. **H2(말의 인과성)** — 기각의 방향이 부호 반대라 «더 세게 밀면 된다»가 아니라 «보상하면
   나빠진다»(G5: 자기 비평을 보상하면 형제 정답에서 멀어지는 문장을 배운다).
4. **H6(여지)** — 성공해도 상한 +3.4pp. 무대 선택(MATH-500/L5 × 8k × 비-thinking)이 실험의
   신호대잡음을 스스로 깎았다.
5. **H4(라벨)** — 설명력 낮음. 라벨이 좋아도 3·5 가 막혀 있었다.
6. **H7/H8** — 두 «자리» 설계의 기각. 위 1~3 의 특수 사례다.

## 3. 사슬이 실제로 끊어진 자리 (검증한 숫자만)

1. 내부 신호는 **난이도**를 읽는다: 풀링 AUC .825, 문제평균↔p_group ρ +.51, 분산의 **77%가 문제 간**.
2. 같은 신호는 **문제 안에서 .577 [.441,.718]** — 혼합문제 38개뿐이라 .5 도 .65 도 배제 못 한다.
3. GRPO 그룹 중심화는 정의상 1의 성분을 어드밴티지에서 제거한다 → 보상이 볼 수 있는 신호는 2 뿐.
4. 문제 안에서 살아남는 유일한 자는 **형제 답 일치 .754**(발화행 .814) — self-consistency 이지
   단일 롤아웃의 자기지식이 아니다.
5. 말로 낸 메타는 문제 특정적이지만(Jaccard .058 vs .008) **진단적이지 않다**(오류 시인 5.1% 정답 /
   5.9% 오답, 확신 .973 / .966).
6. 그 말은 자기 계산을 **남의 말보다 덜** 움직인다(중심이동 own .0049 < donor .0106; IG 짝차이
   −.035 [−.042,−.029]; 방향 AUC .490).
7. 행동 채널은 문맥 안에서 닫혀 있다: 첫 답 재기입 **85~86%**, 두 번째 답 정답 **0/1,248**,
   심은 redirect 의 **95.6%** 자기취소; 바꾼 286행 중 정답 **0**, 새 오답 **80.8%**.
8. 그래서 RL 의 판단 변수는 스텝 1 에 한 부류로 붕괴하고(redirect .000, 강제행 rescue .000)
   메타 스팬 항의 그룹 내 분산은 0 → **한 스텝도 비자명한 gradient 가 없었다.**
9. 보상 없는 대조(M_G1)는 발화만 .31→.43 올리고 held-out 은 **.744 → .744**.
10. 설령 전부 작동했어도 천장은 pass@8−pass@1 = **+7.5pp**, 그중 +4.2pp 는 maj@8 이 이미 회수 —
    **실효 여지 +3.4pp**. 사슬은 «신호 없음»이 아니라 **«신호가 GRPO 가 못 보는 축에 있고,
    말과 행동의 채널이 닫혀 있다»**는 자리에서 끊어졌다.
