## 0. ⛔철회 (2026-08-17, 같은 날 적대검토)

**§1.2 · §1.3 · §1.8 의 난이도 대역 결론은 철회한다.** 층을 **대조군 N 의 성적**(`acc_N`)으로
정의했고, 그것은 회귀 효과를 메타의 효과로 읽는 설계다. 같은 층에서 재집계하면:

```
acc_N==0 층 (n=55) 에서 −N :
  R 진짜 +5.15pp [+1.21,+10.30]   S 어절섞기 +4.55pp   B 정형문 +3.64pp   D 남의것 +2.42pp
                                   └─ 의미를 파괴해도, 아무 말이나 넣어도 오른다 ─┘
  같은 층 R−B = +1.52pp [−3.03,+6.67]   ← 0 을 품는다
```

**독립 기준(사람이 매긴 MATH level)으로 자르면 부호가 반대다:**

| 층 | n | R − B |
|---|---|---|
| L4+L5 | 153 | **−3.59pp** [−6.86, −0.54] |
| L5 | 72 | **−5.56pp** [−10.19, −1.62] |
| L1+L2 | 83 | −1.00pp [−4.02, +2.21] |

⇒ **"어려운 문제에서 자기점검이 +5pp 도움"은 성립하지 않는다. 오히려 해롭게 나온다.**

⚠ **단, 절단이 살아 있는 대안설명이다.** `cont_R` 의 no-boxed 비율이
`acc_N==0` 층 **78.2%**, L5 **48.6%**, L1 3.7% 이고 `grade()` 는 boxed 가 없으면 무조건 0 이다.
진짜 자기점검이 의심을 주입해 재유도를 유발하면 이어쓰기가 길어지고 700토큰 캡에 더 자주
걸린다 — 정형문은 의심을 안 주니 짧다. **지금 산출물로는 "메타가 답을 망친다"와
"메타가 절단을 늘린다"를 분리할 수 없다**(N/B/D/S 팔의 이어쓰기가 저장돼 있지 않다).

**⇒ 현재 상태: 부호를 모른다.** 이 문서의 §3~§6 설계는 §1.2/§1.3 이 참일 때의 것이므로
절단 통제 측정 전에는 채택하지 않는다. 무너진 것: `+5.15pp` · 게이팅 96% 분해 · 천장 표.
살아남은 것: §1.1 · §1.4 · §1.5 · §1.6 · §1.7 (전부 `acc_N` 층화와 무관하거나 층 내부 대조).

이 오류는 **이 저장소의 기록된 규율 위반**이다 — *"층화는 처치군·대조군 성적으로 정의 금지
(gs0 등 독립 기준)"*. 같은 실수를 같은 대화 안에서 두 번 했다.

## 1. 측정 기반

전부 `Qwen/Qwen3-4B` · MATH-500 300문제 · 접합 프로브 k=6.
접합 프로브 = 같은 풀이를 중간(frac 0.6)에서 자르고 메타 다섯 종을 끼운 뒤 각각 6번 재생성·재채점.
본문이 고정이라 메타 이외의 것이 섞이지 않는다.

산출 코드: `mini_abl/{splice_probe,alarm_probe,alarm_probe2,grid_probe}.py` (스크래치패드).

⚠ **여기서 구조적 모순이 나온다.**
그룹 상대 보상의 gradient 는 **프론티어**(0 < p̂ < 1)에서만 생기는데,
메타의 이득은 **완전 실패**(p̂ ≈ 0)에서만 나온다. **두 대역이 겹치지 않는다.**
이것이 "왜 안 됐나"의 가장 깊은 후보다. 대응: 롤아웃 k 를 8 → 16 으로 올려
p̂=0 이던 문제를 프론티어로 끌어온다.

### 1.5 현행 신호(PMI-shift)의 판정

정본 decoy 생성기(`src/training/_decoy_utils._rule_based_decoy`)로 재측정.
판정 기준: **진짜 경보(n=41) > 헛경보(n=115)** 를 높게 매기는가 (AUC).

| 신호 | AUC | |
|---|---|---|
| **PMI-shift (`pos_full`, 라이브)** | **0.457** [0.363, 0.559] | 못 가림 |
| `pos_rev_only` | 0.498 **[0.461, 0.539]** | **확정 널** (구간이 좁다) |
| **정답만 보기 (`gold_shift`)** | **0.400** [0.306, 0.499] | **거꾸로 — 유의** |
| `meta_len` (음성 대조군) | 0.598 [0.489, 0.699] | **현행보다 높다** 🚨 |
| `−surprise` | 0.656 [0.552, 0.752] | 실신호 |
| `−confidence` | 0.635 [0.550, 0.724] | 실신호 |
| `−surprise` + `−confidence` | **0.714** [0.624, 0.803] | 거의 독립 (r=0.17) |

세 가지가 확정됐다.

**① 부호 뒤집기 벌(`derail = −2.0`)이 발화하지 않는다.** 헛경보 115건 중 **2건**.
잘 푸는 문제의 `pmi_open` 중앙값이 **+6.2 nats** 라 부호가 뒤집힐 조건에 닿지 않는다.

**② 음성 대조군이 현행 공식을 이긴다.** `dcpo_rmeta_forms.py` 의 `NEG_len_only` 주석에
적어 둔 기각 조건 — *"이것이 상위권에 오르면 위의 전부가 길이의 대리"* — 에 그대로 걸렸다.

**③ 이긴 조합에 PMI 를 도로 넣으면 0.714 → 0.677 로 떨어진다.** 보태는 게 아니라 잡음이다.

### 1.6 그런데 PMI-shift 는 "일을 했나"는 잰다

같은 본문 위에서 **진짜 메타(R)** 와 **어절만 섞은 메타(S)** 를 짝지어 비교:

```
T2·K1·P1 (현행)    C − S = +0.318 [+0.157, +0.481]   ★유의하게 구별함
T1·K1·P1 (정답만)  C − S = −0.333 [−0.479, −0.196]   ★부호가 반대
```

**정답만 보면 부호가 뒤집힌다** — 어절이 깨진 문장은 모델이 무시하고 원래 경로를 유지해
gold 확률이 유지되고, 진짜 메타는 의심을 주입해 gold 확률을 낮추기 때문이다.
**오답 대조가 그 공통 성분을 지우고 부호를 바로잡는다. 대조는 필요하다.**

층별로 보면 그림이 선명하다:

```
주장함  · 맞힘 (헛경보)  −0.226      정오답 차이   0.06
주장함  · 틀림 (참경보)  −0.166
주장없음 · 맞힘          −0.387      주장 여부 차이 0.16
주장없음 · 틀림          −0.315
```

**무슨 말을 했나에는 민감(0.16), 그 말이 맞았나에는 둔감(0.06).**

### 1.7 근본 원인 — 티처포싱

메타 자리에서 잰 "정답 믿음"이 **이 문제를 맞힐지 예측하지 못한다.**

```
6/6 맞히는 문제   PMI_open 중앙값 +6.52
6/6 틀리는 문제   PMI_open 중앙값 +6.38     AUC(맞힘>틀림) 0.539 [0.461, 0.615]
```

`logp(gold | 문맥)` 은 *"정답 문자열을 이어 붙이면 얼마나 그럴듯한가"* 를 묻는다.
우리가 알고 싶은 것은 *"모델이 스스로 풀어서 거기 도달하는가"* 다.
**수학에서 이 둘의 간극이 곧 난이도 전부다.** 티처포싱은 그 길을 건너뛰고 도착지만 채점한다.

⇒ 보상이 "잘못됐다"기보다 **진짜 있는 양을 재는데 그게 우리가 원하는 양이 아니었다.**
그리고 이 대상 착오는 PMI 만의 문제가 아니라 **티처포싱으로 만든 모든 신호의 문제**다 —
`gold_shift`, `decoy_shift`, `pos` 계열이 전부 같은 이유로 무너졌다.

### ⛔[철회 — §0 참조] 1.8 천장은 데이터가 정한다

```
천장 = 어려운 문제 비율 × 거기서의 이득(+5.15pp)

어려운 층  18%  →  +0.93pp     (지금 MATH-500 · Qwen3-4B)
           30%  →  +1.55pp
           50%  →  +2.58pp     ★게이팅이 실패해도 순이득 +0.61pp
           70%  →  +3.61pp
```

**데이터 선택이 보상 설계보다 큰 레버일 수 있다.**
그리고 이것이 지금까지 정확도가 계속 "차이 없음"으로 나온 이유를 소급 설명한다 —
**찾던 효과가 측정 잡음보다 작았고, 작았던 이유는 애초에 딸 게 없었기 때문이다.**

```
정확도 (쌍대, 300문제)   SE 0.94pp   95% 해상도 ±1.85pp
천장                      +0.93pp
```

## 2. Four habits (Gandhi et al., arXiv 2503.01307) 와의 대조

| | Gandhi | 우리 |
|---|---|---|
| 과제 | Countdown (탐색 게임) | 경쟁 수학 |
| 행동 설치 | **SFT/priming** | SFT |
| 보상 | **정답만** | 정답 + R_meta + 일곱 항 |
| 행동이 살아남는 이유 | **정답률을 실제로 올려서** | — |

Gandhi 에서 되돌아가기가 살아남은 이유는 Countdown 에서 **실제로 정답률을 올리기 때문**이다.
수학 풀이는 대부분 한 방향이고, 모델이 이미 76% 를 맞힌다. 그리고 우리 실측이 말한다 —
**자기점검의 순효과 −2.00pp.**

⇒ **정답만 주는 RL 이 메타를 죽이는 것은 버그가 아니라 정답이다.**
우리가 "정형문 붕괴 72.1%" 라 부른 것은 **모델이 −2pp 짜리 행동을 무해화한 것**이고,
실제로 정형문 롤아웃의 정답률이 더 높았다 (R_corr 0.864 vs 0.839).

⇒ 순서가 이렇게 되어야 한다:

```
먼저   자기점검이 이득이 되는 자리를 만든다   (어려운 문제 · 게이팅)
그다음 행동을 심는다                         (SFT)
마지막 정답만 보고 RL                        (보상을 복잡하게 만들지 않음)
```

**지금 우리는 반대로 하고 있다** — 손해인 행동에 보상을 붙여 억지로 살려 두고 있다.

## 3. 보상 설계

### 3.1 A · 결과 보상 — 유지

답이 맞았나. 바깥 채점기가 준다. **모델이 못 속인다.**

### 3.2 B · 메타 내용 보상 — 후보 다섯, 하나만 고른다

| 후보 | 무엇을 재나 | 정답 필요 | 상태 |
|---|---|---|---|
| 위치 믿음이동 (`pos_full`, 현행) | 메타 앞뒤 정답 믿음 | 필요 | 영향력만 (AUC 0.457) |
| 문맥 믿음이동 | 내 메타 vs 남의 메타 | 필요 | 0.527 |
| 답 직전 이동 | 본문을 다 지난 뒤 | 필요 | **0.783** ⚠참경보 n=5, 미검정 |
| **`drive`** | 내 뒷 본문을 실제로 이끌었나 | **불필요** | **0.674** ⚠n=5, 미검정 |
| 경보 채점 | 주장 × 실제 정오답 | 필요 | 못 속임, 미구현 |

⚠ **보상으로 쓰면 안 되는 것 둘.** `−surprise`(0.656)와 `−confidence`(0.635)는 판별력이
확인됐지만 **최적화하면 무너진다** — 가장 안 놀라운 문장이 정형문이고(PMI-shift 가 애초에
막으려던 그 붕괴), 확신은 0.1 로 고정하면 그만이다. **진단 지표로만 쓴다.**

### 3.3 C · ★발화 게이트 — 신설, 이득의 96%

```
p̂ = 이 문제를 그룹이 얼마나 잘 푸나 (롤아웃 k 개)

R_gate = (메타를 냈나 ? +1 : −1) × (1 − 2·p̂)      [메타 경계 토큰에]

p̂ 높다 (쉽다)   → 메타를 내면 벌, 안 내면 상
p̂ 낮다 (어렵다) → 메타를 내면 상
```

★ **`p̂` 를 정답률 대신 그룹 답 일치율(자기일관성)로 바꾸면 정답을 한 번도 안 본다.**
프로젝트의 노벨티("다 안 보고 학습시킬 수 있다")가 여기 달려 있다. **미검정.**

⚠ **구현 전제**: 그룹 안에 낸 롤아웃과 안 낸 롤아웃이 **섞여 있어야** 학습된다.
지금 발화율 0.98 이라 분산이 없다. `w_emit` 을 먼저 0 으로 내려야 게이트가 배울 여지가 생긴다.

### 3.4 D · 끄는 것 — 아홉 항에서 셋으로

| 항 | 현재 | 왜 끄나 |
|---|---|---|
| `dcpo_w_emit` | 0.1 | **무조건 발화에 상 — 게이트와 정면 충돌** |
| `dcpo_w_cal` | 0.3 | 앞선 판정에서 기각 |
| `dcpo_w_format` | 0.35 | 형식만 남기고 내용을 죽이는 경로 |
| `dcpo_len_cost` | 0.08 | 길이가 이미 음성 대조군에서 신호를 이긴다 — 혼동원 |
| `dcpo_trunc_open` | 0.3 | 같음 |
| `dcpo_meta_floor` | 0.0 | 사장 |
| `dcpo_meta_len_cap` | 96 | 발화 0회 |

남기는 것: `w_corr`, `w_meta`, `w_gate`(신설). 이것이 예전에 성공했던
`archive/launchers_pre_rq3/h100std_shiftonly.yaml` 구성에 가장 가깝다.

### 3.5 E · 결합 규칙 — 더하기에서 곱하기로

```
지금   A = w_corr·Â_corr·[답]  +  w_meta·Â_meta·[메타]
고침   A = w_corr·Â_corr·[답]  +  w_gate·게이트·[메타경계]
                               +  w_meta·(Â_meta × 결과부호)·[메타]
```

지금은 더하기라 **"일은 했는데 틀린 답으로 이끈 메타"가 자기 토큰에서 상을 받는다.**
흔적: b4p2 에서 `acc_with` − `acc_without` 격차가 **+19.9pp → +9.2pp** 로 좁아졌다 —
학습이 갈수록 메타가 답에 영향을 덜 줬다. 두 상을 따로 수확하는 타협에 안착한 것으로 보인다.

## 4. 개악 방지

### 4.1 ★구조로 막는다 — 아래로 못 뚫리게

```
지금  메타를 내면 무조건 상
      → 학습이 실패하면 "쓸모없는 메타를 항상 내는" 상태로 수렴
      → 대조군보다 나쁘다

제안  메타를 내는 것 자체에 작은 고정 비용, 도움이 증명될 때만 그 비용을 넘는 상
      → 학습이 실패하면 "메타를 안 내는" 상태로 수렴
      → 대조군과 같아진다. 더 나빠지지 않는다
```

**실패의 방향이 안전한 쪽이 된다.**

### 4.2 장치 목록

| 개악 방식 | 실측 사례 | 장치 |
|---|---|---|
| Goodhart | `−surprise`/`−conf` 는 최적화하면 정형문으로 | 보상은 바깥에서 검증되는 것에만 |
| 역효과 대역 | 5/6 대역 −6.41pp (주장 시 −16.7pp) | 대역별 발화율을 **따로** 찍는다 |
| 무효 레버 | `derail` 벌 115건 중 2건 발화 | 발사 전 발화 검사, 0이면 무효 |
| 음성 대조군에 짐 | `meta_len` 0.598 > 현행 0.457 | **길이만 주는 네 번째 팔**을 같이 돌린다 |
| 사후 기준 이동 | 헤드라인 5회 번복 전례 | 중단 조건을 **발사 전**에 적는다 |
| 팔 정체 오인 | 9시간 66런 무효 전례 | 이름이 아니라 **매니페스트 diff** 로 확인 |

## 5. 주 지표 — 셋을 계층으로

| | 지표 | 지금 값 | 해상도 | 쓰임 |
|---|---|---|---|---|
| 조종 | **발화 게이팅** `P(메타\|쉬움)` | 0.98 | — | 이득의 96% |
| 조종 | **경보 판별력** `J = TPR − FPR` | +0.193 | ±0.133 | 나머지 4% |
| 확인 | 정확도 (쌍대·전층) | −2.00pp | ±1.85pp | 최종 판정만 |

**정확도를 조종에 쓰지 않는 이유**: 95% 해상도 ±1.85pp 인데 천장이 +0.93pp 다.
지금까지 다섯 번, 잴 수 없는 것을 재고 "차이 없음"이라 적었다.

⚠ **G7 부호 검사**: 발화율만 낮추면 어려운 문제의 +5.15pp 도 같이 잃는다.
지표는 발화율 단독이 아니라 **"쉬우면 안 내고 어려우면 낸다"의 격차**여야 한다.

## 6. 12시간 계획

| 구간 | 자원 | 무엇 | 게이트 |
|---|---|---|---|
| **H0–H2** | 로컬 A100 | **천장 검정** — 어려운 문제 150~300개에서 +5.15pp 재현? | ⛔재현 안 되면 노드 안 씀 |
| **H2–H3** | 로컬 | **신호 검정** — 정답 예측력(1단계) + 어절섞기 대조(2단계) | 살아남는 칸 없으면 경보 채점으로 |
| **H3–H4** | — | **결정** — 보상 확정 · 차분 승인 · **중단 조건 기록** | 승인 게이트 (§9 네 칸) |

### 6.1 H0–H2 · 천장 검정

접합 프로브를 어려운 데이터에서 반복. **확인할 것 하나**: 어려운 층에서 +5.15pp 가 재현되나,
그리고 그 층이 몇 %인가.

```
재현된다     →  천장 +2.6~3.6pp. 계속 진행.
재현 안 된다 →  ⛔노드를 쓰지 않는다. 자기점검은 계산 실수는 잡아도
                 "모르는 기법"은 못 만든다는 뜻이고, 접근 자체를 다시 봐야 한다.
```

### 6.2 H2–H3 · 신호 검정 (두 단계)

```
1단계  신호가 "이 롤아웃이 맞을지"를 예측하나.  못 하면 잡음.
2단계  그 예측력이 메타 덕분인가, 그냥 문제 난이도인가.
       어절 섞기를 대조군으로 같은 검사를 반복한다.
```

**2단계가 없으면 "쉬운 문제 탐지기"에 속는다** — 그건 `R_corr` 가 이미 가진 정보다.
`R_meta` 의 일은 *"정답이냐"* 가 아니라 *"이 결과에서 메타의 몫이 얼마냐"* 다.

같이 풀리는 것: 답직전·`drive` 칸을 제대로 된 표본으로 재측정(지금 셋 다 참경보 n=5 에
막혀 있다) · 자기일관성이 `p̂` 를 대신하나 · 답 누출 검사(메타가 다음 단계를 미리 말해
`drive` 를 부풀리는가).

### 6.3 H4–H10 · 학습 네 팔

| 팔 | 보상 | 답하는 것 |
|---|---|---|
| 대조 | 정답만 (GRPO) | **못 이기면 전부 무의미** |
| 현행 | + PMI-shift, `w_emit 0.1` | 지금 것이 보태나 |
| **게이트** | + 조건부 발화, `w_emit 0` | **96% 예측이 맞나** |
| 음성 | + 길이만 | 이기면 위 셋이 전부 길이의 대리 |

학습 데이터는 **open math** 에서 난이도 대역을 골라 뽑는다 (MATH-500 은 500문제라 학습용이
못 된다). ⚠ 완전 실패 대역은 그룹 보상이 0 이 되므로 롤아웃 k 를 8 → 16 으로 올려
그 문제들을 프론티어로 끌어온다 (§1.2 모순).

### 6.4 H10–H12 · 쌍대 평가

같은 문제·같은 시드·네 팔 동일. **전층**으로 — 프론티어 한정은 해상도를 2.5배 악화시킨다
(전층 500 SE 0.60 vs 프론티어 195 SE 1.54).

## 7. 미결 · 위험

- **`drive` 와 답직전 칸이 미검정** (참경보 n=5). H2–H3 이 이걸 닫는다.
- **자기일관성이 `p̂` 를 대신하는지 미검정.** 노벨티가 여기 달려 있다.
- **어려운 데이터에서 +5.15pp 재현 여부 미확인.** H0–H2 의 전부.
- **경보 탐지기가 정규식**이다. `claims_error` 의 오분류가 §1.4 를 흔들 수 있다.
  (배선검사: 층 크기 208/55/37 재현, 네 칸 부호 재현. 그러나 표본을 눈으로 보면
  "not properly accounted for" 같은 표현을 놓친다.)
- **중간 층(0 < acc_N < 1, n=37) 이 −1.80pp** 로 음수다. 프론티어에서 메타가 해롭다는
  §1.2 와 일관되지만, 이 층의 주장/무주장 분해는 아직 안 했다.
- **정본 코드 변경은 전부 승인 대기.** 이 문서는 제안이고 차분이 아니다.
