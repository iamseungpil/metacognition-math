# 의도 대 증거 — OOD 축 감사 (2026-08-03)

**질문**: 이 프로젝트의 선언된 의도(*"OOD에서 distillation이 약하다 → 메타인지 습관을 강화하는
metacognitive RL을 제안한다"*)를 우리 자신의 데이터가 지지하는가.

## 1. 의도는 문서에 정확히 적혀 있다

`README.md:14-21`:
> **메타인지적 자기증류**로 **OOD(어려운 도메인, AIME)에 강건한 수학 추론**을 만든다.
> North-star 가설: 메타인지 행동은 **in-distribution 정답 암기보다 분포 밖 문제에서
> 더 강건하게 일반화한다.**

**AIME를 OOD 축으로 이름까지 지목**하고 있다. 학습 분포(`verl_train_meta_mix.parquet`)는
gsm8k 1830 · hendrycks_math 2938 · omni-math 576이므로, held-out 1030 중
**gsm8k·MATH500은 ID이고 AIME2024만 OOD**다.

## 2. ★ 그런데 데이터가 그 가설을 반박한다

보존된 산출물을 성분별로 분해했다(math_verify 독립 재채점, 문항 페어드 부트스트랩 10,000회).

**16k 예산**

| 벤치 | 축 | 프라이밍<br>(gandhi−base) | **PMI-shift**<br>(shiftonly−gandhi) | 기타 헤드<br>(pmishift−shiftonly) | 우리−baseSFT+GRPO<br>(pmishift−base) |
|---|---|---|---|---|---|
| gsm8k | ID | +3.30 p<.001 | **−1.70 p=.025** | −0.25 p=.303 | +1.35 p=.076 |
| MATH500 | ID | +4.85 p<.001 | **+4.38 p<.001** | +4.78 p<.001 | **+14.00 p<.001** |
| **AIME** | **OOD** | **+8.75 p=.006** | **−2.50 p=.073** | +2.50 p=.094 | **+8.75 p=.009** |

**4k 예산 (재확인)**: AIME 프라이밍 **+10.00 p=.003** · PMI-shift **−4.58 p=.014** ·
기타헤드 +4.17 p=.037 · 패키지 +9.58 p=.003.

**판정 세 줄.**

1. **OOD(AIME)에서 가장 크게 기여하는 성분은 distillation(meta-SFT 프라이밍)이다** — +8.75~+10.00pp.
   *"OOD에서 distillation이 약하다"* 는 전제가 **우리 데이터에서 지지되지 않는다.**
2. **우리가 제안하는 metacognitive RL 보상(PMI-shift)은 OOD에서 부호가 음수다** —
   −2.50pp(16k, n.s.) · **−4.58pp(4k, p=.014)**. 즉 **기여가 목적 축에서 반대 방향이다.**
3. PMI-shift가 양수인 유일한 곳은 **MATH500 = 학습 분포와 같은 ID 벤치**(+4.38~+4.85pp)다.
   gsm8k(ID·포화)에서도 −1.70~−2.08pp로 음수다.

⇒ **시스템 전체는 OOD에서 작동한다(+8.75pp). 그러나 주장하는 이유와 반대 이유로 작동한다.**
OOD를 나르는 것은 프라이밍이고, 메타인지 보상은 ID를 나른다.

## 3. 실험 설계가 의도를 조준하지 않고 있다

- **`docs/PREREGISTRATION_rq3v2_base_replication.md`에 OOD 언급이 0회다.**
  주 판정 A3는 **held-out MATH500 = ID 벤치**다.
- OOD 축의 표본은 **AIME 30문항 하나뿐**이다. omni-math는 학습에 들어 있어 OOD가 아니다.
  즉 **북극성 가설의 검정력이 n=30에 걸려 있다.**
- in-training val594에도 OOD 셀이 없다(전 9벤치가 학습 분포).

⇒ **OOD 축이 계측되지 않았다.** 지금 구조로는 north-star 가설을 확증도 반증도 할 수 없다.

## 6. 결론이 여는 것 / 닫는 것

**닫는 것**
- *"PMI-shift가 OOD 강건성을 준다"* 는 주장. 우리 데이터가 **반대 부호**를 준다.
- OOD 주장을 MATH500으로 뒷받침하는 모든 서술. MATH500은 ID다.

**여는 것**
- **OOD 축을 실제로 계측하는 것** — AIME 30문항 하나로는 north-star를 검정할 수 없다.
  최소한 학습에 없는 hold-out 도메인이 수백 문항 필요하다.
- **프레이밍 재고**: 우리 데이터가 지지하는 문장은
  *"메타인지 프라이밍이 OOD를 나르고, 인과 보상은 ID solvable-hard를 나른다"* 이다.
  이건 원래 주장보다 약하지만 **측정된 주장**이다.
- **노브 정리**: 47개 죽은 노브 제거 + 나머지를 명시적 기본값으로 승격
  (*"설정 안 함"* 과 *"0"* 을 구분 가능하게).
