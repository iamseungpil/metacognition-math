# b3p2 설계안 — 수리된 init 위의 DCPO 재도전 (0812 초안 · ⛔발사 전 사용자 확인 필요)

## 전제 (이 문서가 서 있는 사실들)

- **init 은 `models/b2p3_vunmask_sft`** — EXP-0812f 로 검증된 수리판(gs0 meta-first 0%·think 100%·정확도 0.6470). 구 b3p 는 "생각 없이 메모부터 쓰는" 학생을 받아 시작했고(C-034), 새 팔은 건강한 습관에서 시작한다.
- **비교 상대는 `rq3v2f_b2p3v`**(진행 중) — 같은 init 의 VANILLA_GRPO. 이 쌍이 처음으로 "**같은 건강한 출발점**에서 경로+보상 패키지의 효과"를 잰다.
- **경로 진단(E-158)**: 구 b3p 손상의 유력 기전은 DCPO region 경로의 mean-only advantage(±1.7, clip~0%)가 GDPO whiten(±4.5, clip 27-38%)보다 gradient 가 작은데 `entropy_coeff 0.001` 은 동일 → **region 경로에 상대 엔트로피 압력 ~2.6배**. 단 EXP-0812d 게이트 판정대로 이 귀속은 미확정(관측만 유효)이다.
- **R_cal 은 11결함 확정**(감사①): 침묵=만점, 스칼라 conf 출처 불일치, cal membership 부재로 양의 advantage 불가, anchor_norm 자기잠금 등.

## 3안 (1안이 기본 제안)

### 1안 (기본): `entropy_coeff=0` 단일 변경 DCPO
- **차분**: config 한 키(`entropy_coeff: 0.001 → 0.0`). 코드 무변경.
- **논리**: E-158 기전 가설의 최소 검정. 구 b3p 대비 변수 둘(init 수리 + entropy 압력 제거)이지만, b2p3v 가 init 축을 통제해 주므로 "같은 init 에서 DCPO(entropy0) vs VANILLA" 비교가 성립.
- **판정선(사전등록 초안)**: gs300 robust MATH500 n8 에서 ⓐ b2p3v 대비 쌍대 Δ ⓑ 메타 발화율·meta-first 재발 여부 ⓒ entropy 궤적(0.16 밴드 유지 vs 5.9 폭주 재현).

### 2안: KL 앵커(ref-KL coef>0)로 안정화
- **차분**: config `kl_coef 0 → 0.001~0.01`. 코드 무변경.
- **논리**: 경로 불문 앵커로 이탈 자체를 벌금. 단 습관 보존과 학습 속도를 맞바꾸며, entropy 기전 가설을 직접 검정하지 못함(교란 추가).

### 3안: GDPO 멀티리워드 (pmi_shift 를 채널로)
- **차분**: 보상 라우팅을 GDPO whiten 경로로, pmi_shift/R_cal 을 멀티리워드 채널로 편입. **코드 변경 필요(승인 대상)** — A1(min_prefix_tokens 가드) + A2(floor 자격 AND-게이팅) 최소셋 선행.
- **논리**: 사용자가 물었던 "GDPO 멀티리워드로 pmi_shift" 방향. 단 변수가 많아 1안 결과 없이 발사하면 귀속 불가(0812d 의 교훈 재발).

## R_cal 수리 포함 여부

- 1·2안: **포함하지 않음**(경로/안정화 축만 분리 검정). w_cal=0 유지.
- 3안: A1+A2 최소셋 포함(승인 필요). 나머지 9결함은 후속.

## 발사 조건

1. **b2p3v 관측 우선**: 최소 gs50~100 의 궤적(reward 상승·meta 발화 유지·meta-first 재발 여부)을 본 뒤 발사 — b2p3v 자체가 "정답만 보상해도 습관이 부서지는가"를 답하며, 그 답이 1안의 설계를 바꿀 수 있다.
2. **사용자 확인** — 이 문서의 안 선택(1/2/3 또는 조합)과 발사 시점.
3. 발사 시 체크리스트: .env 소스 · 단일따옴표 count==2 · 정체성 키 3중 가드+잔존0 · lineage 신규(rq3v2f_b3p2) · WANDB 신규 · HF 충돌 0 · G1 CLAIMS grep.
