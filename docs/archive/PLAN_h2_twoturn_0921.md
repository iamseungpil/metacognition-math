## 0. 의도

> **한 번의 풀이 안에서, 자기가 틀린 것을 스스로 다시 풀어 맞추는 습관을,
> 외부 교사 없이 자기 롤아웃만으로 채점해 강화한다.**

세 가지를 못 박는다.
1. **추론은 롤아웃 하나**다. 형제 K개를 뽑아 갈림을 보는 것은 test-time compute 이지
   메타인지가 아니다. 형제·gold 는 **학습 때 채점에만** 쓴다.
2. **형식을 정해 주지 않는다.** 되짚는 말을 우리가 써 넣지 않는다. 밖에서 넣은 말은
   전부 실패했고(§3), 모델이 스스로 쓴 말만 계산을 움직였다.
3. **정확도는 결과이지 목표가 아니다.** 목표는 습관이고, 습관이 값을 하는지는
   파괴율·구제율로 잰다.

### 0.1 의도 3요소와 각 단계의 부합 (★정직하게 적는다)
의도 문장은 **「특정 언어 패턴인 메타인지를, 내부 신호를 활용해, 강화하는 자기 증류」** 다.
2턴 설계는 기울기를 사기 위해 그중 **둘을 일시적으로 내려놓는다.** 숨기지 않고 사다리로 되찾는다.

| 요소 | 뜻 | M_REV(자발 수정) | **H2 2턴** | H3 증류 | H4 라벨제거 | H5 절약 |
|---|---|---|---|---|---|---|
| 특정 언어 패턴 | 모델이 **스스로 쓴** 되짚기 말 | ✅ 그 말에만 크레딧 | ⚠️ **없음** — 2턴은 말이 아니라 프로토콜 | ✅ 단일 패스가 그 말을 스스로 내야 함 | — | — |
| 내부 신호 | **모델 안의** 무엇이 재시도를 켠다 | ✅ 수정 행위·믿음 이동 | ⚠️ **없음** — 무조건 재시도(밀도 1) | ◐ 형식이 내부화됨 | — | ✅ 1턴 확신이 게이트 |
| 자기 증류 | 교사=자기 롤아웃, 외부 교사 없음 | ✅ | ✅ | ✅ | ✅ gold 제거 | ✅ |
| (기울기) | 학습이 실제로 흐르나 | ❌ 밀도 0.5%, 12k 이득 +0.07pp | ✅ 밀도 100% | ✅ | ✅ | ✅ |

**거래의 내용**: M_REV 는 의도에 완벽히 맞지만 기울기가 없었고, H2 는 기울기가 있지만
의도의 절반을 미룬다. 그래서 **H3 는 선택 사항이 아니다.** H3 에서 단일 패스가 2턴 행동을
스스로 내지 못하면, 우리가 얻은 것은 «2패스 프로토콜»이지 메타인지가 아니다 — 그 경우
논문의 주장은 성능이 아니라 진단으로 내려간다.

## 1. 설계 — 한 턴에 무슨 일이 일어나는가

**학습 한 턴** (문제 하나, K=8 롤아웃)
1. 문제 q → 정책이 8번 푼다(각 6,144토큰) → 각 행의 첫 답 `\boxed{X}`.
2. **리셋**: 2턴 프롬프트 = q + 「네 이전 시도의 답은 X였다」 **사실 한 줄만**.
   풀이 본문은 주지 않는다(주면 −10.4pp, 사실만 주면 +3.4pp).
3. 정책이 **모든 행에서** 다시 푼다(6,144토큰) → `\boxed{Y}`. **최종 답 = Y**.
4. 채점: R1 = X 정오, R2 = Y 정오 (1단계는 gold, 4단계에서 형제 다수결로 교체).
5. 보상 배분
   - 1턴 스팬 : **R1** (+ 기준 정책으로의 KL 앵커 — 1턴을 일부러 망치지 못하게)
   - 2턴 스팬 : **R2 + α⁺·max(R2−R1, 0) − α⁻·max(R1−R2, 0)**,  α⁻ = 2α⁺
6. GRPO 갱신. 그룹 중심화는 기존대로 결과 보상에만 걸린다.

**추론** : 같은 2턴 프로토콜, **롤아웃 1개**, 형제 없음, gold 없음, 총 12k 토큰.
base 단일 패스 12k(.8795)와 **같은 예산**에서 비교한다.

### 왜 «고르기»를 배우게 하지 않는가
모델은 문제 안에서 자기 답의 정오를 구분하지 못한다(은닉 프로브 .512, 언어화 확신 .53,
헤징 .499, 형제 기하 .511~.569; 결정 발화 SFT 는 발화율 .834 를 얻고 풀이가 .046 으로 붕괴).
그래서 X 와 Y 중 고르는 분류기를 학습시키지 않는다. **2턴을 무조건 취하고,
맞는 답을 깨뜨리는 쪽에 두 배 벌을 준다.** 배우는 것은 선택이 아니라 «망치지 않기»다.

## 2. 목표는 숫자 하나다 — 파괴율

무조건 재시도의 손익(8k+8k 실측, L5-800×8):

| 항목 | 값 |
|---|---|
| 정답 행 C / 오답 행 W | 5,517 / 883 |
| 구제 p_fix | **.377** (333행) |
| 파괴 1−p_keep | **.078** (433행) |
| 순 | **−1.56pp** (never .8620 → always .8464) |
| 손익분기 | p_fix / (1−p_keep) > C/W = **6.25**, 현재 **4.81** |

구제율은 이미 충분하다. **문제는 파괴율 하나뿐이다.**

| 파괴율을 낮추면 | 순이득 |
|---|---|
| 6% | +0.03pp |
| 5% | +0.89pp |
| **4%** | **+1.75pp** |
| 3% | +2.62pp |

→ **H2 의 목표: p_fix ≥ .35 를 유지한 채 파괴율 7.8% → 4% 이하.**
비대칭 벌(α⁻ = 2α⁺)이 정확히 이 레버다.

## 4. 사다리 — 앞이 미달이면 뒤는 올리지 않는다

| 단계 | 질문 | 방법 | 관문 |
|---|---|---|---|
| **H1** 출발선 | 6k+6k 리셋 2턴은 어디서 시작하나 | 학습 없음. base 6k 롤아웃 → `always_notx` 6k | **p_fix ≥ .30 ∧ oracle(X∨Y) ≥ .9095**(= base12k+3pp). 미달이면 2턴 축 종료 |
| **H2** 학습 | 파괴율을 반으로 줄일 수 있나 | 밀도 1 · 리셋 · 비대칭 Δ · 1턴 KL | **파괴율 ≤ .04 ∧ p_fix ≥ .35 ∧ 최종 ≥ base12k + 1.5pp ∧ 1턴 정확도 하락 없음** |
| **H3** 증류 | 단일 패스로 옮길 수 있나 | 자기 2턴 성공 궤적 형식 SFT → H2 보상 RL | H2 이득의 **80% 유지 ∧ 토큰 ≤ 1.3배** |
| **H4** 라벨 제거 | gold 없이 되나 | 채점을 형제 다수결로 교체 | 손실 폭 자체가 보고 값 |
| **H5** 절약(나중) | 확신 있으면 재시도를 건너뛰나 | 1턴 확신 → 재시도 여부 | 정확도 유지에 토큰 −30% |

**중단 규칙**: 1턴 정확도가 10스텝 창에서 −.10(사행) · 20스텝 지표 무변화 ·
파괴율이 오히려 상승. 셋 중 하나면 그 자리에서 멈추고 다음 대안으로.
