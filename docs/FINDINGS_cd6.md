작성 2026-09-01. 모든 수치는 독립 감사(10회)를 통과한 값이며, 철회한 판단은 §7에 남긴다.

---

## 1. 한 줄

> **정답 쪽으로 «가이딩하는» 신호는 「답을 알아보는 것」이 병목일 때 작동한다.
> 「답을 찾는 것」이 병목인 다중해 탐색 과제에서는 같은 신호가 무정보이고,
> 대응하는 개입은 탐색이 잘 되고 있을수록 «해롭다».**

---

## 2. 과제의 병목은 «믿음»이 아니라 «탐색»이다

| 측정 | 값 |
|---|---|
| 실패 궤적의 시도 횟수 (중앙) | **55회** — 소진으로 실패한다 |
| 메타 앞 산술 오류 중 메타 뒤에 교정된 것 | **0 / 13** |
| 확신 >0.8 인 사이트 중 실제 오답 | **6 / 131 (4.6%)** — 고확신 구간은 이미 잘 교정됨 |
| 확신 → 최종 정답 AUC | **0.777** — 감시(monitoring)는 실재한다 |
| 문제당 해의 개수 (완전 열거, 중앙) | **11개** (평균 21.1, 최대 114) |

**감시는 되는데 조절이 안 된다.** 그리고 답을 «알아보는» 일은 이 과제에서 계산 한 번이면 된다.

## 3. 정답 가이딩 신호는 무정보다

PMI-shift = `[logp(정답|메타뒤) − logp(미끼|메타뒤)] − [logp(정답|메타앞) − logp(미끼|메타앞)]`

| 측정 | 값 |
|---|---|
| 메타가 정답 믿음을 올린 정도 | **+0.30 nats** (움직이기는 «잘» 한다) |
| 메타의 실제 유도가치 L2 = p_orig − p_abl | **−0.024** |
| 둘의 상관 | **ρ = +0.081, p = 0.35** |
| 가장 잘 맞춘 미끼(연산 하나만 바꾼 것)로 재면 | **ρ = +0.006, p = 0.94** |
| PMI-shift 평균의 구성 | **95%가 «미끼 쪽» 이동** — 정답 쪽이 아니다 |

**믿음은 올라가고 성적은 내려가며, 둘은 무관하다.**

### 자 41개 전부 실패했고, 이유는 공식이 아니다

메타를 «읽지 않는» 프리픽스 통계량 `doom`을 통제하면:

| 자 | ρ(L2) | doom 통제 후 | doom+확신 통제 후 |
|---|---|---|---|
| shift_gold1 (PMI) | +0.081 | +0.032 | +0.010 (p=0.91) |
| shift_setmean (해집합) | +0.146 | +0.103 | +0.081 |
| rb_R3_family | +0.258 | +0.146 | +0.141 |
| V1_all_mean (도치) | −0.275 | −0.218 | −0.221 ← **부호 반대** |
| **doom (메타 안 읽음)** | **−0.311** | — | **−0.245 (p=0.004)** |

**메타를 읽는 자 중 어느 것도, 메타를 안 읽는 통계량을 통제하면 유의하지 않다.**
라벨의 신호가 전부 프리픽스에 있다.

### 그리고 고를 대상이 없다

| 측정 | 값 |
|---|---|
| σ²(자기 메타 4개) − σ²(위약 4개) — 전체 | **−0.0005 [−0.0023, +0.0013]** |
| 같은 것 — 막힘 층 «안에서만» | **+0.00013 [−0.00116, +0.00145]** |
| 오라클 best-of-4 상한 (자기) vs (위약) | +13.09%p vs **+13.00%p** — 순수 선택 잡음 |

내용의 «평균» 효과는 있다(자기 − 위약 = +0.68%p [+0.18,+1.23], 막힘 층).
없는 것은 «퍼짐»이다 — 자기 메타들끼리 서로 다르지 않다.

## 4. ★핵심 — 개입은 상태가 좋을수록 해롭다

같은 절단점에 방향만 다른 블록을 강제로 끼우고, 그 자리가 «실제로 막혔는지»로 층화.
막힘 판정은 **혼잣말을 한 글자도 읽지 않는다** — 메타 없이 8번 재시작해 전부 실패하면 막힘(split-half).

| 층 | n | 기준 | 강제 redirect | 강제 verify |
|---|---|---|---|---|
| 막힘 (재시작 전부 실패) | 366 | 0.022 | **+2.00 %p** (3/3 시드 양수) | +0.63 %p |
| 중간 | 228 | 0.324 | −10.4 %p | −11.1 %p |
| 건강 (>50% 성공) | 303 | 0.827 | **−22.9 %p** | −18.9 %p |

관찰 라벨에서도 독립 재현된다 (유도가치 L2 × 프리픽스 건강도 p_abl):

| 상태 | redirect L2 | verify L2 |
|---|---|---|
| 가망 없음 (p_abl ≤ 0.1) | −0.007 | −0.011 |
| 중간 | +0.005 | −0.085 |
| 잘 되는 중 (p_abl > 0.5) | +0.078 | **−0.272** |

**같은 행동의 부호가 상태에 따라 뒤집힌다.** 그리고 verify는 어느 층에서도 양수가 아니다.

### verify가 해로운 기전

| 측정 | redirect | verify |
|---|---|---|
| 답까지 글자 수 | 812.9 | **263.5** |
| 이후 시도 횟수 | 10.6 | **3.3** |
| 120자 안에 답을 씀 | 2.5% | **64.4%** |
| 확신 >0.8 구간에서 즉시 답 | — | **99.2%** |

**verify는 검산이 아니라 «종료 신호»다.** 그리고 verify가 붙는 자리는 구조적으로
건강한 자리(p_abl 0.156 vs redirect 0.063)라 잃을 것이 많다.
