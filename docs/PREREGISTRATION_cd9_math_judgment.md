## 수정 7 (2026-09-21) — 밀도 1 리셋 2턴으로 전환

### 7.1 M_REV 라인 종결 사유 (3줄)
1. cap 절단으로 PMI 크기 정보가 소실됐다(38스텝 중 26스텝 `clipped_rows == credit_rows`, 사실상 ±cap 이진 크레딧).

3. 크레딧 밀도가 512행 중 10.4행(2.64%)까지 올라도 12k 등예산에서 정확도 이득은 **+0.06pp [−0.70, +0.81]**(CI가 0 포함) — 8k 의 +1.17pp 는 절단 회복분이었다.
→ 밀도 1(전 행 무조건 재시도) 리셋 2턴으로 축 전환.

### 7.2 사다리 H1~H5 (관문은 `docs/PLAN_h2_twoturn_0921.md` §4 원문)

| 단계 | 질문 | 방법 | 관문 |
|---|---|---|---|
| H1 출발선 | 6k+6k 리셋 2턴은 어디서 시작하나 | 학습 없음, base 6k → `always_notx` 6k | p_fix ≥ .30 ∧ oracle(X∨Y) ≥ .9095(=base12k+3pp). 미달이면 2턴 축 종료 |
| H2 학습 | 파괴율을 반으로 줄일 수 있나 | 밀도 1·리셋·비대칭 Δ·1턴 KL 앵커 | 파괴율 ≤ .04 ∧ p_fix ≥ .35 ∧ 최종 ≥ base12k+1.5pp ∧ 1턴 정확도 하락 없음 |
| H3 증류 | 단일 패스로 옮길 수 있나 | 자기 2턴 성공 궤적 형식 SFT → H2 보상 RL | H2 이득의 80% 유지 ∧ 토큰 ≤ 1.3배 |
| H4 라벨 제거 | gold 없이 되나 | 채점을 형제 다수결로 교체 | 손실 폭 자체가 보고 값 |
| H5 절약(나중) | 확신 있으면 재시도를 건너뛰나 | 1턴 확신 → 재시도 여부 | 정확도 유지에 토큰 −30% |

**H2 하위 분할** (같은 관문을 공유하되 항이 다르다):
- **H2a (`score`, 결과형)**: a2 = R2 + α⁺·max(R2−R1,0) − α⁻·max(R1−R2,0), α⁻ = 2·α⁺. knob `SCORE_ALPHA_POS`(1.0)/`SCORE_ALPHA_NEG`(2.0).
- **H2b (`pmi`, 믿음 이동형)**: 2턴 스팬에 SHIFT = (logp_gold − logp_decoy)_close − (·)_open, **연속값·cap 없음**. 열림 자리 = 리셋 알림 직후, 닫힘 자리 = 마지막 \boxed 직전.
- **사전등록 결정**: H2 관문에서 **H2b ≥ H2a** 이면 「믿음 이동 보상 > 결과 보상」 주장을 허용한다. 미달이면 PMI는 진단 전용으로 남기고 학습 신호로 쓰지 않는다.

### 7.3 H1 요인설계와 문맥 선택 규칙
`notice ∈ {none, minority, majority, state} × text ∈ {notx, withtext}`. `state`(합의 상태 고지) 아래 ALL_SAME 행은 2턴을 건너뛴다.
**사전등록된 결정**: H2 의 문맥 = `notx` 셀 중 파괴율이 가장 낮으면서 p_fix ≥ .30 인 셀. `withtext` 셀은 통제 전용이며(기대 −10pp) **절대 채택 대상이 아니다**.

## 0. 의도 (한 문장)

**메타인지 습관은 이미 모델 안에 있다. 부족한 것은 그 습관을 도움이 되는 자리에서만 켜는
판단이며, 그 판단은 모델 자신의 롤아웃에서 만든 인과 라벨로 가르칠 수 있다.**

세 축을 이렇게 챙긴다.

| 축 | 무엇으로 | 약점과 보완 |
|---|---|---|
| 노벨티 | ① 메타 전용 진전 라벨(같은 자리 반사실 Δ̂) ② **판단 조건부 반사실**(같은 자리에 verify/redirect 를 심어 어느 판단이 옳은지 채점) ③ 결과 고정 검증 ④ DERAIL 발화에 음의 이점 ⑤ 온라인 은닉 프로브 | 각 조각은 선행이 있다(Rewarding Progress, Reflect-Retry-Reward, SE probes). 조합과 ②가 새롭다. RRR 재현 팔이 없으면 주장이 서지 않으므로 필수 대조 |
| 메타인지 강화 자기 증류 | 라벨이 자기 롤아웃에서 나오고, 판단이 맞은 자기 메타를 선호 학습(오프라인) + 프로브 일치 이점(온라인) | 프로브만으로는 «내용»을 못 본다. donor 대조로 «내용 효과»와 «멈춤 효과»를 가른다 |
| 성능 | MATH-500 메타 없음 .741 기준, 세금 −0.8pp 를 넘어 동률 이상 | SAVE 밀도가 상한(SAVE 10%·절반 구제 = +2~3pp). 주장은 «세금 없는 동률 이상 + 발화 위치의 선택성» |

왜 Countdown 이 아닌가: Countdown 은 무료 검증기(재계산)가 있어 «내 접근이 옳은가»라는 판단을
계산으로 대체할 수 있고(학습된 자기검산 .878 < 계산기 .908), Qwen3.5 는 학습 없이 .876/.992 로
포화했다. 수학은 pass@1 .741 / pass@8 .782 로 여지가 작고 공짜로 회수되지 않는다.

## 1. 라벨 (학습 없음)

자리 = 롤아웃을 줄 경계에서 자른 지점(앞 10%·뒤 20% 제외). 같은 자리에서 K 개씩 이어 쓴다.

| 조건 | 심는 텍스트 | 쓰임 |
|---|---|---|
| nometa | 없음 | 기준 p̂₀ |
| meta | `\n<meta>\n` (모델이 씀) | Δ̂ = p̂(meta) − p̂₀ |
| donor | 다른 문제의 완성 메타 | 내용 효과 vs 멈춤 효과 |
| verify | 고정 문구 + `decision: verify` | 판단 라벨 |
| redirect | 고정 문구 + `decision: redirect` | 판단 라벨 |

라벨: SAVE p̂₀ ≤ .25 ∧ Δ̂ ≥ +.25 · DERAIL p̂₀ ≥ .75 ∧ Δ̂ ≤ −.25 · 정답 판단 = argmax(p̂ verify, p̂ redirect), 차이 < .25 면 tie.
자기 멈춤 자리(허용판에서 모델이 스스로 메타를 낸 지점)도 같은 라벨을 붙여 «언제 판단»의 정확도를 잰다.

**밀도 게이트**: SAVE < 5% 면 학습 팔 전부 보류(OPD 계열이 3~15% 에서 굶은 전례). tie 가 80% 를
넘거나 redirect 심기의 전환 문구율이 nometa 와 같으면 판단 라벨 무효.

### 8.3 관문

(a) **밀도 관문(1차, 즉시 판정)**: 첫 3스텝 평균 `credit_rows` ≥ 512행의 10%(50행). 미달이면
**rc 75 즉시 중단** → 대안은 주입 2턴(H1~H5, §8.4)으로 복귀.

(b) **25스텝 12k 등예산 평가**: 주 지표는 **비만장일치 부분집합(233문제)** 한정 —
① 수정률 ≥ base×1.5 ∧ ② 정밀도 ≥ base ∧ ③ 부분집합 정확도 +2pp(문제 짝맞춤 부트스트랩 2,000회,
CI 가 0 배제). 전체 800문제는 **안전 지표**로만 본다 — 만장일치 문제 정확도가 base 대비 −0.5pp
이내여야 한다(비만장일치 쪽 학습이 만장일치 쪽을 침식하지 않는지 확인).

(c) **SPONT_PMI ≥ SPONT_SCORE** 이면 「믿음 이동 보상 > 결과 보상」 주장을 허용한다(수정 7 §7.2
H2a/H2b 대결과 동일 형식의 사전등록 결정).

### 8.4 주입 2턴(H1~H5)의 지위 — 보조/교사 후보로 강등

수정 7 의 밀도 1 리셋 2턴 라인은 폐기하지 않고 **강등**한다. H1 첫 셀(6k+6k, 학습 없음) 결과:
none/notx `never` .8098 / `always` .8034 / `oracle` .8702 — 그리고 **1턴 6k 절단이 base 단일
패스 12k(.8795) 보다 7pp 낮게 출발**한다는 경고를 기록해 둔다(`docs/RESULTS_cd9.md` 0921절
"M_REV_PMI_GOLD s2(v2) step50" 항 말미). 이 출발선 결손 때문에 H1 관문(oracle ≥ .9095)은
사실상 6k+6k 예산 분할로는 달성이 어렵다. 주입 축을 다시 올릴 필요가 생기면(§8.3 (a) 밀도 관문
탈락 시가 그 트리거) **1턴 12k 유지 + 2턴 단축**으로 예산을 재설계한다 — 1턴을 절단하지 않고
2턴 재시도 예산만 얇게 얹는 형태.

### 8.5 중단 규칙 (자발 v3)

- **first_correct 10스텝 −.10**: 1턴(첫 답) 정확도가 10스텝 창에서 .10 이상 사행성 하락.
- **파괴율 20스텝 상승**(허용폭 .01): 맞는 답을 틀리게 바꾸는 비율이 20스텝 창에서 허용폭을
  넘어 오름.
- **20스텝 수정률 무변화**: 비만장일치 부분집합의 자발 수정률이 20스텝 동안 유의한 변화 없음.

셋 중 하나면 그 자리에서 멈추고 §8.4 의 주입 2턴 대안으로 전환한다.
