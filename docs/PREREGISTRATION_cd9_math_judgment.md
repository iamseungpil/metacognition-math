# 사전등록 — cd9: 수학 무대, 판단 조건부 반사실 자, 자기 판단의 자기 증류

작성 2026-09-14 · 학습 결과 0건 시점 · 로컬 H100 GPU 2·3 · 모델 Qwen3.5-4B · 사용자 승인 2026-09-13.
이 문서는 관측 후 수정하지 않는다. 판정은 `docs/RESULTS_cd9.md`(원장)에만 쓴다.

## 0. 의도 (한 문장)

**메타인지 습관은 이미 모델 안에 있다. 부족한 것은 그 습관을 도움이 되는 자리에서만 켜는
판단이며, 그 판단은 모델 자신의 롤아웃에서 만든 인과 라벨로 가르칠 수 있다.**

세 축을 이렇게 챙긴다.

| 축 | 무엇으로 | 약점과 보완 |
|---|---|---|
| 노벨티 | ① 메타 전용 진전 라벨(같은 자리 반사실 Δ̂) ② **판단 조건부 반사실**(같은 자리에 verify/redirect 를 심어 어느 판단이 옳은지 채점) ③ 결과 고정 검증 ④ DERAIL 발화에 음의 이점 ⑤ 온라인 은닉 프로브 | 각 조각은 선행이 있다(Rewarding Progress, Reflect-Retry-Reward, SE probes). 조합과 ②가 새롭다. RRR 재현 팔이 없으면 주장이 서지 않으므로 필수 대조 |
| 메타인지 강화 자기 증류 | 라벨이 자기 롤아웃에서 나오고, 판단이 맞은 자기 메타를 선호 학습(오프라인) + 프로브 일치 이점(온라인) | 프로브만으로는 «내용»을 못 본다. donor 대조로 «내용 효과»와 «멈춤 효과»를 가른다 |
| 성능 | MATH-500 메타 없음 .741 기준, 세금 −0.8pp 를 넘어 동률 이상 | SAVE 밀도가 상한(SAVE 10%·절반 구제 = +2~3pp). 주장은 «세금 없는 동률 이상 + 발화 위치의 선택성» |

왜 Countdown 이 아닌가: Countdown 은 무료 검증기(재계산)가 있어 «내 접근이 옳은가»라는 판단을
계산으로 대체할 수 있고(학습된 자기검산 .878 < 계산기 .908), Qwen3.5 는 학습 없이 .876/.992 로
포화했다. 수학은 pass@1 .741 / pass@8 .782 로 여지가 작고 공짜로 회수되지 않는다.

## 1. 라벨 (학습 없음)

자리 = 롤아웃을 줄 경계에서 자른 지점(앞 10%·뒤 20% 제외). 같은 자리에서 K 개씩 이어 쓴다.

| 조건 | 심는 텍스트 | 쓰임 |
|---|---|---|
| nometa | 없음 | 기준 p̂₀ |
| meta | `\n<meta>\n` (모델이 씀) | Δ̂ = p̂(meta) − p̂₀ |
| donor | 다른 문제의 완성 메타 | 내용 효과 vs 멈춤 효과 |
| verify | 고정 문구 + `decision: verify` | 판단 라벨 |
| redirect | 고정 문구 + `decision: redirect` | 판단 라벨 |

라벨: SAVE p̂₀ ≤ .25 ∧ Δ̂ ≥ +.25 · DERAIL p̂₀ ≥ .75 ∧ Δ̂ ≤ −.25 · 정답 판단 = argmax(p̂ verify, p̂ redirect), 차이 < .25 면 tie.
자기 멈춤 자리(허용판에서 모델이 스스로 메타를 낸 지점)도 같은 라벨을 붙여 «언제 판단»의 정확도를 잰다.

**밀도 게이트**: SAVE < 5% 면 학습 팔 전부 보류(OPD 계열이 3~15% 에서 굶은 전례). tie 가 80% 를
넘거나 redirect 심기의 전환 문구율이 nometa 와 같으면 판단 라벨 무효.

## 2. 자 (라벨 위에서 기각 시험)

| 자 | 통과 조건 (셋 다) |
|---|---|
| 은닉 프로브(메타 끝 은닉벡터 → Δ̂ / 정답 판단) | SAVE vs DERAIL AUC ≥ .65 · **결과 고정 AUC ≥ .55** · donor 자리에서 점수 낮음 |
| 갈림 토큰 엔트로피(자리 직전 64토큰) | SAVE 자리 > 나머지 (언제 신호가 로짓에 있는가) |
| 메타 전후 엔트로피 감소, 자기확신, Quiet-STaR식 이득, PMI-shift | 위와 같음. cd7 에서 전부 결과 고정 AUC ≤ 0 이었으므로 대조 한 줄 |

## 3. 학습 팔 (GPU 2 본론, GPU 3 대조) — `scripts/local/run_math_arm.sh`

답 스팬은 정답 보상만. 메타 스팬만 팔마다 다르다(region-split).

| 팔 | 메타 스팬 신호 | 역할 |
|---|---|---|
| M_JUDGE | 결정이 정답 판단과 일치 +1 / 반대 −1 (가중 0.5) | 본론(오프라인 라벨) |
| M_PROBE | 프로브 예측 일치 이점 | 본론(온라인) |
| M_RAND | 라벨 섞음 | 프로브/라벨이 잡음이면 M_JUDGE 와 같아야 함 |
| M_G0 / M_G1 | 없음 (plain / 허용 프롬프트) | 세금·침식 곡선 |
| RRR 재현 | 재시도 성공 시 반성 스팬 보상 | 노벨티 경계 |

## 4. 판정 지표와 중단 (트리거는 `gate_judgment.py`, 중단은 rc 75·`ABORTED.txt`)

첫 번째 판정은 정확도가 아니다. held-out 자리(학습에 안 쓴 문제)에서 10스텝마다:

1. **판단 일치율**(자기 메타의 결정 = 정답 판단) 이 학습 전보다 오른다.
2. **발화 세 곡선**: SAVE 발화 ↑, DERAIL 발화 ↓, NEUTRAL 불변. 셋 다 오르면 «자주 말하기»의 재현 = 실패.
3. 정확도 ≥ M_G0 − 1pp (세금 없음).

중단(3스텝 연속): 발화율 < .20(메타 항 있는 팔) · 메타 안 `\boxed` > .02 · 상용구율 > .05 · 정확도 < M_G0 − 1pp.
중단되면 사다리의 다음 팔이 자동 제출된다. 재시도 래퍼는 rc 75 를 재시도하지 않는다.

## 5. 이미 확정된 사실 (관측, 2026-09-13)

- Qwen3.5-4B 수학 메타의 93~97% 는 `decision:` 줄이 없다 → 파서 `form="math"`(결정 선택). 결정 줄을 필수로 두면 RL 의 첫 학습 내용이 «decision: verify 붙이기»가 된다.
- 허용판 메타 세금 −0.8pp(MATH-500), 강제판 −0.6pp. Countdown 은 −3~5pp.
- AIME25 .558 / HMMT25 .271 (32k 예산, 잘림 4~8%) — 사용 가능한 기준선.
