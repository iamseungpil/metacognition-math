Korean translation of `paper/en` (Two Teachers in the Middle). Same sections, numbers, citations, labels,

(두괄식, 한 문장 한 역할, 단문 비율 >= 60%, em-dash 0, 번역투·계사 대용 0, 명사형 종결 금지).

## Layout (ICML 2026, 2026-10-12 final pass)

- `main.tex`: ICML 2026 submission layout (`icml2026.sty`, two columns, anonymous), built with XeTeX (tectonic) instead of pdfLaTeX.
  Deviations from the ICML template, kept because Hangul needs XeTeX:
  - `fontspec` + `kotex` (xetexko). `times.sty` (loaded by `icml2026.sty`) has no TU-encoded fonts under XeTeX, so Latin text is set
    in TeX Gyre Termes (`texgyretermes-*.otf` from the tectonic bundle, Times metrics); math stays Computer Modern as in the template.
  - Hangul: Noto Serif CJK KR (body) and Noto Sans CJK KR (sans), loaded by file name with fontspec `Path=` from
    `/home/ubuntu/.local/share/fonts/`, scale 0.92; `\linespread{1.05}` for Hangul line height.
  - Running head: Hangul is taller than the 6.25pt height that `icml2026.sty` allows, so the running title is wrapped in a 6pt `\raisebox`.
  - Impact Statement heading in Korean with the English name in parentheses.
  - The Korean main text is longer than the English one, so it may exceed 8 pages; the English draft is the one held to the page limit.
  Macros (`\Tblind`, `\Tkeep`, `\todo`, notation, theorem environments 명제 / 가정 A1-A4) are identical to the English `main.tex`.
- `sections/*.tex`: one file per English file (`abstract, intro, related, method, experiments, discussion, conclusion, appendix,
  related_full, app_theory, app_setup, app_results`). Cross-references use Korean style (`\ref{sec:x}절`, `그림~\ref{}`, `표~\ref{}`,
  `부록~\ref{}`, `명제~\ref{}`). Percentage points are written `\%p`.
- `refs.bib`: copy of the English `refs.bib` (142 entries, all verified against the arXiv API). Re-copy it when the English one changes.
- `figures/`: Korean figure PDFs, generated by the English figure package (see below). No figure code lives here.
- `build_main_ko.pdf`: last build.

## Regenerate the Korean figures

The figure code is shared with the English draft (`paper/en/figures/`). `figs_i18n.py` holds the language
switch: `FIG_LANG=ko` maps every user-visible label through one dictionary (`KO`), sets the font to
Noto Sans CJK KR (registered with `matplotlib.font_manager.fontManager.addfont`) and writes to this folder.
Default `FIG_LANG=en` is unchanged and writes to `paper/en/figures/`.

```
cd paper/en/figures
FIG_LANG=ko /home/ubuntu/miniforge3/bin/python3 make_figs.py               # all Korean figures -> paper/ko/figures/
FIG_LANG=ko /home/ubuntu/miniforge3/bin/python3 make_figs.py fig_tokens    # only the named figures
FIG_OUT=/some/dir /home/ubuntu/miniforge3/bin/python3 make_figs.py         # any language into another folder (e.g. for checks)
```

- A new or changed English label prints `[i18n] no Korean label for '...'` in Korean mode: add it to `KO` in
  `figs_i18n.py`. Wrap new labels with `tr("...")`; layout values that must differ for Korean use `pick(en, ko)`
  (used for the teaser legend offset and the budget end labels; Korean glyphs are taller).
- Left in English on purpose: method, benchmark and model names; model-written text (discourse markers in
  `fig_markers`, token text in `fig_tokens`, "Wait, let me re-check" and the test-time strip in `fig_overview`); file paths.
- After a data refresh (`--refresh`, see the English README), redraw both languages.
- Check: `pdftoppm -png -r 130 -singlefile figures/<fig>.pdf /hdd_data/seungpil/tmp/<fig>` and look at each PNG
  (clipping, overlap, missing glyph boxes).

## Build

```
cd paper/ko
mkdir -p /hdd_data/seungpil/tmp/paper_build_ko/out
/hdd_data/seungpil/texenv/bin/tectonic -X compile main.tex --outdir /hdd_data/seungpil/tmp/paper_build_ko/out
cp /hdd_data/seungpil/tmp/paper_build_ko/out/main.pdf build_main_ko.pdf
```

The first build downloads `kotex`/`xetexko` and a few Latin Modern files from the tectonic bundle (cached after).
Remaining warnings (2026-10-12 audit): no overfull boxes; a font-shape warning (no Hangul italic, upright substituted); underfull boxes in the appendix `p{}` tables and one bibliography entry; tectonic notes that fontconfig
scanned system fonts by absolute path.
